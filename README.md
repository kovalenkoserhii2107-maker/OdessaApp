# Одесса: Контур

Игра: [открыть «Одесса: Контур»](https://kovalenkoserhii2107-maker.github.io/OdessaApp/).

Основной публичный репозиторий: [OdessaApp](https://github.com/kovalenkoserhii2107-maker/OdessaApp). `origin` настроен на него; обычный `git push` отправляет изменения туда. Remote `legacy` содержит прежний адрес уже недоступного репозитория.

Рабочее название OdessaApp. Сюжетная управленческая игра в альтернативной Одессе: Труханов, Бедрега и Ткач видят разные стороны программы «Контур».

## Запуск

Нужен Node.js 24 (см. `.nvmrc`).

```sh
npm ci
npm run dev
```

Открыть http://127.0.0.1:5173/OdessaApp/.

- **Google** — существующая авторизация Firebase. Домен запуска должен быть разрешён в Firebase Authentication.
- **Попробовать демо** — отдельное локальное сохранение, без входа; удобно для разработки и знакомства с игрой.
- Выберите героя, откройте дело, выберите решение и подходящего сотрудника. Цена списывается из ресурса его ведомства.
- Сотрудник занят до следующей смены. Личные и общие ответы сохраняются в журнале.
- «Завершить смену» позволяет пройти прототип без ожидания. Автоматическая смена происходит через 12 часов; при возвращении учитывается пропущенное время.
- «Сменить героя» позволяет увидеть другие стороны **этой же локальной** кампании.

## Что реализовано

18 дел: три сюжетных этапа и три личных дела на каждого героя. Дела открываются по `minTick` и `requires`. Решения проверяют полномочия героя, наличие дела, стоимость, навык, занятость и усталость сотрудника. Метрики ограничены 0–100. Последствия приходят другим героям через заданное количество смен. Карта использует имеющиеся контуры районов; маркеры сюжетных мест расположены схематически.

Интерфейс работает на компьютере и телефоне: список дел, фильтры, карта с масштабированием, журнал, команда, доступное с клавиатуры досье. PWA содержит офлайн-оболочку, локальные шрифты и иконки. Chromium предлагает установку, когда браузер считает её доступной; iOS показывает инструкцию Safari. Новая версия устанавливается после нажатия «Обновить приложение».

## Границы этой версии

**Firebase пока используется только для входа. Серверной совместной кампании и синхронизации между устройствами нет.** Обычная кампания хранится в `localStorage.odessa_save` для этого браузера, а не отдельно для каждого Google-аккаунта. Демо хранится в `odessa_demo_save`. Не используйте это как разграничение доступа нескольких людей. Для настоящей игры на троих нужны серверное хранилище, комнаты, права на роль и серверный пересчёт.

12 часов — текущий темп прототипа после изменений Antigravity, не окончательное продуктовое решение. Раньше обсуждался часовой пересчёт. В этой версии эффект выбора применяется сразу, отложенные последствия — на сменах. `clockOffset` сохранён только для совместимости старых данных.

## Проверки и сборка

```sh
npm run test       # логика, последствия, ограничения, старые сохранения
npm run build      # строгая проверка TypeScript + Vite + PWA
npm run check      # обе проверки
npm run preview    # http://127.0.0.1:4173/OdessaApp/
npm run icons      # PNG из существующей SVG-иконки
```

На телефоне четыре закреплённые нижние вкладки: входящие, карта, журнал и команда. Досье открывается на весь экран: сначала решение, затем исполнитель. Кнопки продолжения и отправки остаются видимыми при прокрутке.

PWA проверяется на production preview / HTTPS, не на Vite dev. Путь задаётся при сборке:

```sh
VITE_BASE_PATH=/ npm run build             # собственный домен, корень сайта
VITE_BASE_PATH=/OdessaApp/ npm run build    # Pages репозитория OdessaApp
npm run build                             # /OdessaApp/ по умолчанию
```

`start_url`, scope и иконки разрешаются относительно manifest. Идентификатор приложения и offline fallback используют тот же путь, что Vite. После каждой сборки проверяются согласованность путей и наличие иконок; создаются `404.html` для старых/вложенных ссылок и `.nojekyll` для Pages.

Публикация требует явного адреса репозитория и пути, чтобы смена `origin` не отправила сборку в другое место:

```sh
DEPLOY_REPOSITORY=https://github.com/kovalenkoserhii2107-maker/OdessaApp.git VITE_BASE_PATH=/OdessaApp/ npm run deploy
```

Команда проверяет проект и отправляет сборку в `gh-pages`. **Push исходников и создание ветки gh-pages не включают сайт автоматически.** В выбранном репозитории должен быть доступен и настроен GitHub Pages на `gh-pages` / root. Перед переустановкой ярлыка проверить HTTP 200 для сайта, manifest и его start URL. Старый ярлык с ошибочным корневым адресом может потребовать удаления и повторного добавления после публикации; не очищайте данные браузера с сохранением кампании.

27 сентября пользователь сделал OdessaApp публичным, после чего GitHub Pages включён для `gh-pages` / root. Актуальный путь игры — `/OdessaApp/` с учётом регистра. Старый `/odessa-app/` больше не используется. Ранее Pages не включался из-за ограничения тарифа для приватного репозитория.

## Где продолжать

- [`AI_HANDOFF.md`](AI_HANDOFF.md) — текущее состояние и порядок продолжения для ИИ/разработчиков.
- [`GAME_DESIGN_DOCUMENT.md`](GAME_DESIGN_DOCUMENT.md) — игровой замысел.
- [`docs/QA.md`](docs/QA.md) — проверенные сценарии и ограничения проверки.
- `src/game/content.ts` — весь текущий сюжет, роли, сотрудники, варианты решений.
- `src/game/engine.ts` — чистые переходы игрового состояния.
- `src/game/storage.ts` — проверка и восстановление сохранений.
- `src/hooks/useGameState.ts` — браузерное хранение и таймер.

Игровые события и мотивы вымышлены. Материалы не утверждают, что реальные люди или организации совершали описанные действия. Портрет из исходной переписки не находится в репозитории.
